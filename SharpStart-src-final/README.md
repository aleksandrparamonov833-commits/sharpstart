# SharpStart

SharpStart — русскоязычная платформа для изучения C# с 31 маршрутизируемым уроком, серверной проверкой практики, редактором C# и профилем с синхронизацией прогресса.

## Требования

- Windows 10 или 11.
- .NET 10 SDK.
- VS Code и расширение C# от Microsoft — по желанию.

Сервер использует системную библиотеку SQLite `winsqlite3.dll` и Windows AppContainer для изолированного запуска кода. Запуск редактора на других операционных системах не поддерживается.

## Запуск в VS Code

1. Распакуй архив и открой в VS Code папку проекта — ту, в которой лежит `SharpStart.csproj`.
2. Открой встроенный терминал в этой папке.
3. Запусти `dotnet run`.
4. Перейди по адресу, который появится в терминале; профиль запуска по умолчанию — `http://localhost:5147`.

Или открой PowerShell в каталоге проекта и выполни:

```powershell
dotnet run
```

Для остановки сервера нажми `Ctrl+C` в терминале.

## Демо-вход

- Почта: `student@sharpstart.ru`
- Пароль: `SharpStart2026!`

Можно зарегистрировать отдельный аккаунт. Пароли хранятся как PBKDF2-хеш с индивидуальной случайной солью, а не как открытый текст.

## Возможности

- 31 урок в последовательности «Основы → Практика → ООП → Дальше»; теория, проверки и задания лежат в `Content/lessons.json`.
- Отдельные адреса уроков вида `/lesson/variables`; страница урока загружается напрямую и после обновления.
- Monaco Editor с подсветкой C#, автодополнением, подсветкой диагностик, вводом для `Console.ReadLine()` и запуском по `Ctrl+Enter`.
- Практические решения проверяются сервером по скрытым тестам. Пользовательский C# запускается в ограниченной Windows AppContainer-песочнице с лимитом времени, памяти, размера кода и частоты запросов.
- Аккаунты, чтение, решённые задания, завершённые уроки и учебные дни хранятся в `App_Data/sharpstart.db` (SQLite). При первом запуске остаток старой базы аккаунтов из `App_Data/accounts.json` импортируется автоматически.
- В профиле есть дашборд, прогресс, уведомления, советы, XP, серия учебных дней и достижения.
- Справочник находится на `/docs.html`, поддерживает поиск по темам и коду.

## Данные и безопасность

База SQLite создаётся в `App_Data` при первом старте; не удаляй её, если хочешь сохранить аккаунты и прогресс. Файл `accounts.json`, если он есть, нужен только для одноразового импорта старых аккаунтов. Демо-аккаунт создаётся, когда в новой базе нет пользователей.

Редактор предназначен для локального учебного запуска. Песочница рассчитана на Windows и ограничивает возможности процесса, но этот проект не предназначен для публикации открытого сервиса для незнакомых пользователей без отдельного аудита и усиления изоляции.

## Структура

- `Program.cs` — ASP.NET Core API, регистрация, авторизация, уроки и серверная проверка практики.
- `SqliteStore.cs` — SQLite-хранилище аккаунтов и прогресса.
- `WindowsSandboxRunner.cs` — компиляция и запуск кода в Windows AppContainer.
- `Content/lessons.json` — структура и содержание уроков.
- `wwwroot/` — сайт, редактор, стили и справочник.
- `App_Data/` — локальные данные пользователей; не включаются в распространяемый архив.

## Разработка

```powershell
dotnet build
node --check wwwroot/app.js
node --check wwwroot/docs-favorites.js
```

Для быстрой проверки работающего локального сайта запусти сервер в одном терминале и во втором выполни `.\scripts\smoke-test.ps1`. По умолчанию сценарий проверяет `http://localhost:5147`; для другого адреса сначала задай переменную `$env:SHARPSTART_URL`.

Для добавления урока добавь запись в `Content/lessons.json` с уникальным `id` и `slug`, содержанием, вопросами и упражнениями. У упражнения с автопроверкой должны быть серверные тесты в поле `tests`; ожидаемые ответы и тест-кейсы не отдаются публичным API.
