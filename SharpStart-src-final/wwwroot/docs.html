КРАТКАЯ СПРАВКА

Документация C#.

Основные понятия языка с короткими примерами. Открой тему, чтобы увидеть объяснение и синтаксис.

01Как устроен C#

C# — строго типизированный язык программирования. Приложения выполняются в среде .NET. SDK содержит компилятор и инструменты разработки, а Runtime запускает готовые приложения.

using System; Console.WriteLine("Привет, мир!");

Создай консольный проект командой dotnet new console, сохрани код в Program.cs и запусти dotnet run.

02Переменные и типы

Переменная связывает имя со значением. Тип определяет, какие данные она хранит и какие действия доступны. Типичные варианты: int, decimal, string, bool.

string name = "Алия"; int lessons = 3; decimal price = 1990m; bool isReady = true; var message = $"{name}: {lessons}";

Используй decimal для денежных сумм, int для целых чисел, string для текста и bool для true/false.

03Операторы и условия

Арифметика: +, -, *, /, %. Сравнения ==, !=, <, >, <= и >= возвращают true или false. Один знак = присваивает значение.

int score = 75; if (score >= 60) { Console.WriteLine("Сдано"); } else { Console.WriteLine("Попробуй ещё раз"); }

Операторы && и || объединяют условия. Для нескольких вариантов можно использовать else if или switch.

04Циклы

for удобен, когда число повторений известно. foreach перебирает все элементы коллекции, while работает, пока условие остаётся истинным.

for (int i = 0; i < 3; i++) { Console.WriteLine(i); } foreach (string topic in topics) { Console.WriteLine(topic); }

Следи, чтобы условие цикла могло стать ложным. Иначе программа будет повторять его бесконечно.

05Методы

Метод именует отдельное действие. Параметры передают входные данные, return возвращает результат, а void означает, что результат не возвращается.

static int Sum(int a, int b) { return a + b; } int result = Sum(4, 6);

Выноси повторяющиеся действия в методы с понятными именами. Так решение проще переиспользовать и проверять.

06Массивы и коллекции

Массив имеет фиксированный размер. List<T> можно расширять. Dictionary<TKey,TValue> хранит пары «ключ — значение».

int[] scores = { 80, 95, 72 }; var topics = new List<string> { "Основы" }; topics.Add("Практика");

Для List и Dictionary добавь using System.Collections.Generic;. Перебирай элементы через foreach.

07Классы и интерфейсы

Класс описывает данные и поведение, объект — конкретный экземпляр. Свойства управляют доступом к данным. Интерфейс задаёт контракт, которому следует тип.

class Student { public string Name { get; set; } = ""; } var student = new Student { Name = "Саша" };

Создай объект оператором new. Используй интерфейсы, когда нескольким разным типам нужно предоставить одинаковое поведение.

08Исключения и null

try/catch обрабатывает ожидаемые ошибки. null означает отсутствие объекта. Оператор ?? задаёт запасное значение.

string? nickname = null; string shown = nickname ?? "Гость"; Console.WriteLine(shown);

Обрабатывай только те исключения, с которыми можешь что-то сделать. Не скрывай ошибку пустым блоком catch.

09Асинхронность и LINQ

async/await помогает дождаться длительной операции, не блокируя поток. LINQ фильтрует и преобразует коллекции: Where оставляет подходящие элементы, Select преобразует их.

var even = values.Where(x => x % 2 == 0); Console.WriteLine(string.Join(", ", even));

Для LINQ обычно нужен using System.Linq;. Добавляй async только тогда, когда внутри есть асинхронная операция.

10Команды .NET CLI

Командная строка .NET помогает создать, запустить и собрать проект.

dotnet --version  # версия SDK; dotnet new console  # новый проект; dotnet run  # запуск; dotnet build  # сборка

Для первых упражнений подойдёт консольный проект с файлом Program.cs.

11Ввод и преобразование

Console.ReadLine получает строку. Чтобы использовать введённые цифры как число, преобразуй строку. TryParse помогает сообщить о неверном формате без исключения.

string input = Console.ReadLine() ?? "";
if (int.TryParse(input, out int number)) Console.WriteLine(number * 2);
else Console.WriteLine("Введите целое число");

При гарантированном корректном формате можно использовать int.Parse. Для денег подходит decimal.TryParse.

12Строки и форматирование

Строки неизменяемы: методы возвращают новое значение. Интерполяция вставляет переменные в текст, а Trim убирает пробелы по краям.

string name = "Алия";
string cleanName = name.Trim();
Console.WriteLine($"Привет, {cleanName}!");

Свойство Length возвращает длину строки в кодовых единицах UTF-16. Сравнение через == учитывает регистр.

13Массивы, списки и словари

Массив хранит фиксированный набор одного типа и использует нулевые индексы. List<T> можно расширять. Dictionary<TKey,TValue> ищет значение по уникальному ключу.

int[] values = { 3, 5, 8 };
foreach (int value in values) Console.WriteLine(value);
var names = new List<string> { "Алия" };
var scores = new Dictionary<string, int> { ["Алия"] = 10 };

Перед чтением неизвестного ключа словаря проверь ContainsKey или используй TryGetValue.

14Свойства, конструкторы и инкапсуляция

Свойство управляет чтением и изменением данных объекта. Конструктор задаёт обязательное состояние при создании. Инкапсуляция скрывает детали и защищает правила типа.

class Account
{
    public string Owner { get; }
    public decimal Balance { get; private set; }
    public Account(string owner) => Owner = owner;
    public void Deposit(decimal amount) { if (amount > 0) Balance += amount; }
}

Предпочитай методы, которые выражают намерение, прямому изменению внутреннего состояния.

15Наследование и полиморфизм

Наследник получает доступ к защищённым и открытым членам базового класса. Виртуальный метод можно переопределить; вызов через общий базовый тип выберет реализацию объекта.

class Animal { public virtual string Sound() => "..."; }
class Cat : Animal { public override string Sound() => "Мяу"; }
Animal pet = new Cat();
Console.WriteLine(pet.Sound());

Используй наследование для действительно общего поведения. Для составных отношений часто лучше композиция.

16Интерфейсы, enum и record

Интерфейс описывает контракт поведения. enum задаёт именованный набор вариантов. record удобен для моделей данных со сравнением по значениям.

interface IPrintable { string Print(); }
enum Status { New, InProgress, Done }
record TaskCard(string Title, Status State);
class Note : IPrintable { public string Print() => "Заметка"; }

Объявляй только те варианты и члены, которые понятны в предметной области.

17Исключения и nullable-типы

Исключение сообщает о нештатной ситуации. Обрабатывай ожидаемые ошибки узко и давай пользователю понятное действие. Nullable-тип явно разрешает отсутствие значения.

string? nickname = null;
string shown = nickname ?? "Гость";
if (int.TryParse("42", out int age)) Console.WriteLine(age);

Не используй пустой catch: это скрывает причину проблемы. Проверь null до обращения к объекту.

18LINQ и асинхронность

LINQ выражает выборку данных через Where и преобразование через Select. async/await помогает дождаться операции ввода-вывода, например сетевого ответа.

using System.Linq;
int[] values = { 1, 2, 3, 4 };
var even = values.Where(value => value % 2 == 0);
foreach (int value in even) Console.WriteLine(value);

Не делай вычислительный код асинхронным без ожидающей операции. Цепочки LINQ держи читаемыми.

19Отладка и тестирование

Читай первое сообщение компилятора, исправляй по одной ошибке и проверяй пример вручную. Тестируй обычный случай и границы: пустое значение, ноль и минимальный набор.

static int Add(int a, int b) => a + b;
if (Add(2, 3) != 5) throw new Exception("Сумма рассчитана неверно");

В Visual Studio можно поставить breakpoint, посмотреть значения и пройти программу по шагам. Маленькие проверки упрощают локализацию ошибки.
